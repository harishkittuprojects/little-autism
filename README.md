# Little Plant Autism Educational Academy / Little Little Plant Autism Residential Home

> **"Don't Focus Only on the Disability. Discover the Ability. Nurture the Talent. Empower the Child."**  
> *Every Child Deserves a Chance to Shine!*

A modern, responsive, and accessible educational, therapeutic, and residential website for **Little Plant Autism Educational Academy** (Little Plant Special Children Care Trust / Little Little Plant Autism Residential Home).

---

## 🌟 Key Highlights & Features

- **Children We Support:** Dedicated section detailing the 12 developmental and special educational conditions (ASD, ADHD, ID, Down Syndrome, CP, Speech Delay, GDD, Learning Disabilities, etc.) for children aged 3–18 years.
- **8 Core Development Programs:**
  1. Speech and Communication Development
  2. Behaviour Therapy and Positive Behaviour Support
  3. Occupational Therapy
  4. Special Education and Individualized Learning
  5. Activities of Daily Living (ADL)
  6. Physical Activities and Swimming
  7. Music and Creative Activities
  8. 24/7 Residential Hostel and Daycare (Target: June 2027)
- **Our Dream Campus at Jinnaram, Telangana:** Land acquired, Bhoomi Puja performed on 22 August 2026, building completion targeted for 31 May 2027.
- **Statutory Registrations & CSR Partnerships:** 80G tax exemption, 12A/12AB non-profit registration, Form 10BD compliance, and Telangana RPwD documentation.
- **Interactive Features:**
  - Responsive mobile navbar with solid backdrop and slide-down drawer
  - Interactive Parent Inquiry & CSR Tour Booking Modal
  - Parent & Staff Portal authentication card with show/hide password and validation
  - Real-time search and category filtering on Services page
  - Scroll-triggered AOS (Animate On Scroll) animations

---

## 🛠️ Technology Stack

- **Frontend:** React 18
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom Olive Green & Soft Sage Palette)
- **Icons:** Lucide React
- **Animations:** AOS (Animate On Scroll)
- **Routing:** React Router v6

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized bundle will be created in the `dist` folder.
